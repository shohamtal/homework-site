תנאים בפייתון if, elif ו-else

תוכנית טובה מחליטה לבד: אם הציון גבוה, מדפיסים "מצוין". אם לא, בודקים את התנאי הבא. כאן כותבים if, elif ו-else, משווים ערכים ורואים איזה ענף רץ. כדאי להיזכר קודם בחידות אם אז ובמשתנים וטיפוסים. אחר כך ממשיכים ללולאות בפייתון.

הרעיון

תנאי הוא שאלה שהתשובה שלה True או False. שואלים בעזרת סימני השוואה:

==שווה!=שונה<קטן>גדול<=קטן או שווה>=גדול או שווה

if

אם התנאי True, השורות המוזחות מתחתיו רצות. אם False, מדלגים עליהן. אחרי התנאי באות נקודתיים, והשורות שבפנים זזות 4 רווחים.

if lives == 0:
    print("Game over")

elif ו-else

elif הוא "ואם לא, אז אולי". בודקים לפי הסדר, ורק הענף הראשון שמתקיים רץ. else רץ כשאף תנאי לא התקיים.

if temp >= 30:
    print("Hot")
elif temp >= 18:
    print("Nice")
else:
    print("Cold")

and ו-or

and: שני התנאים חייבים להיות True. or: מספיק שאחד מהם True. כך מחברים שתי שאלות לתנאי אחד.

if age >= 12 and height >= 140:
    print("You can ride")
if day == "Fri" or day == "Sat":
    print("Weekend")
לזכור: בשרשרת של if, elif ו-else רץ ענף אחד בלבד: הראשון שהתנאי שלו True. אם אף אחד לא, רץ ה-else.

מעבדה: איזה ענף ירוץ?

התוכנית מחשבת ציון סופי: ציון במבחן ועוד בונוס, אבל לא יותר מ-100. אחר כך היא בוחרת מילה לפי הציון. הזיזו את המחוונים, נחשו איזה ענף ירוץ, ולחצו "שורה הבאה" כדי לבדוק. שורות שמדלגים עליהן לא נצבעות.

= במקום ==

      
בתנאי שואלים, לא שמים ערך. לכן כותבים ==. עם = אחד פייתון עוצר עם שגיאה.

    print("Perfect")

print("Keep going")

    print("Keep going")

    

    

      
סדר לא נכון של elif

    grade = "Excellent"

שאלות שכולם שואלים

  

    
מה ההבדל בין elif לעוד if?

    
elif נבדק רק אם כל התנאים שלפניו היו False, ולכן בשרשרת רץ ענף אחד בלבד. כמה if נפרדים נבדקים כל אחד לבד, ואז יכולים לרוץ כמה מהם. נסו במעבדה.

    
חייבים לכתוב else?

    
לא. else הוא רשות. בלעדיו, אם אף תנאי לא התקיים, פשוט לא קורה כלום וממשיכים לשורה שאחרי התנאי. כותבים else כשרוצים לטפל גם ב"כל השאר".

    
מה ההבדל בין and ל-or?

    
עם and התנאי True רק אם שני החלקים True. עם or מספיק שאחד מהם True. "יש כרטיס and יש מקום" מחמיר יותר מ"יש כרטיס or יש מקום". תרגלו למטה.
