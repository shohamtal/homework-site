מערכת אי-שוויונות ואי-שוויון כפול שני תנאים, פתרון אחד

לפעמים x צריך לעמוד בשני תנאים ביחד. פותרים כל תנאי לבד, מציירים את שניהם על אותו ציר, ומחפשים איפה הם נפגשים. במעבדה מזיזים מחוונים ורואים מה קורה, ובתרגול מקבלים רמזים במקום תשובות.

הרעיון

"וגם": איפה שניהם נכונים

x > −2 וגם x ≤ 3.

הפתרון הוא הקטע הירוק, החלק שבו שני הקווים נמצאים ביחד.

אי-שוויון כפול

את אותו פתרון כותבים בקיצור:

−2 < x ≤ 3

קוראים: x גדול מ-−2 וקטן או שווה ל-3. כלומר x נמצא בין שני המספרים.

"או": מספיק שאחד נכון

x < −1 או x > 4.

כאן הפתרון הוא שני החלקים, כל מה שצבוע בירוק.

איך פותרים: כל תנאי פותרים בדיוק כמו אי-שוויון רגיל ממעלה ראשונה, כולל הכלל של היפוך הסימן בכפל או חילוק במספר שלילי. אחר כך מציירים את שני הפתרונות על אותו ציר ומחברים: "וגם" זה החלק המשותף, "או" זה הכול ביחד.

שלוש מלכודות

פעולה רק על האמצע

באי-שוויון כפול 1 < x + 4 < 9 יש שלושה חלקים. מה שעושים לאמצע, עושים לכולם:

1 − 4 < x + 4 − 4 < 9 − 4

ומקבלים −3 < x < 5.

חילוק בשלילי באי-שוויון כפול

−6 ≤ −2x < 4. מחלקים ב-−2: שני הסימנים מתהפכים.

3 ≥ x > −2

ואז מסדרים מהקטן לגדול: −2 < x ≤ 3. כל סימן הולך עם המספר שלו.

"וגם" בלי חלק משותף

x > 4 וגם x < 1. אין מספר שגם גדול מ-4 וגם קטן מ-1.

אז כותבים: אין פתרון. זו תשובה נכונה, לא טעות.

בדיקה מהירה: בחרו מספר אחד מתוך הקטע הירוק והציבו אותו בשני התנאים המקוריים. שניהם צריכים לצאת נכונים. אחר כך בחרו מספר מחוץ לקטע, ולפחות אחד מהם צריך לצאת לא נכון.

שאלות שכולם שואלים

איך פותרים אי-שוויון כפול?

עושים את אותה פעולה על שלושת החלקים ביחד, עד ש-x נשאר לבד באמצע. למשל 1 < 2x − 3 ≤ 7: מוסיפים 3 לכל החלקים ומקבלים 4 < 2x ≤ 10, ואז מחלקים ב-2: 2 < x ≤ 5. תרגלו למטה.

מה ההבדל בין "וגם" לבין "או" במערכת אי-שוויונות?

"וגם" אומר ש-x צריך לקיים את שני התנאים, אז הפתרון הוא רק החלק המשותף על הציר. "או" אומר שמספיק תנאי אחד, אז הפתרון הוא כל מה שצבוע, משני התנאים ביחד. החליפו במעבדה בין "וגם" ל"או" ותראו את ההבדל.

מתי למערכת אי-שוויונות אין פתרון?

כשמחברים עם "וגם" ושני התנאים לא נפגשים על הציר. למשל x > 4 וגם x < 1: אין מספר שעומד בשניהם. אם התנאים נוגעים רק בנקודה אחת, כמו x ≥ 2 וגם x ≤ 2, הפתרון הוא רק x = 2.
