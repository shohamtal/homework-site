אי-שוויונות ממעלה ראשונה

במשוואה יש תשובה אחת, כמו x = 3. באי-שוויון יש הרבה תשובות, כמו כל המספרים שגדולים מ-3. פותרים כמעט כמו משוואה, עם כלל אחד חשוב שצריך לזכור. במעבדה מזיזים מחוונים ורואים מה קורה, ובתרגול מקבלים רמזים במקום תשובות.

הרעיון

ארבעה סימנים

x > 3: x גדול מ-3.

x ≥ 3: x גדול מ-3 או שווה ל-3.

x < 3: x קטן מ-3.

x ≤ 3: x קטן מ-3 או שווה ל-3.

טיפ: הצד הפתוח של הסימן תמיד פונה למספר הגדול.

מציירים על ציר המספרים

זה x > 3. העיגול ריק, כי 3 עצמו לא גדול מ-3.

אם היה כתוב x ≥ 3, העיגול היה מלא, כי גם 3 מתאים.

הכלל החשוב: פותרים כמו משוואה. אבל כשכופלים או מחלקים את שני הצדדים במספר שלילי, הסימן מתהפך: > הופך ל-<, ו-≥ הופך ל-≤.

שלוש מלכודות

שכחו להפוך

−2x < 6. מחלקים ב-−2, מספר שלילי, אז הסימן מתהפך: x > −3.

בדיקה: x = 0 גדול מ-−3. מציבים: −2 · 0 = 0, ו-0 < 6. נכון.

הופכים רק בכפל ובחילוק

x − 3 > −5. מוסיפים 3 לשני הצדדים: x > −2.

חיבור וחיסור לא הופכים את הסימן, גם כשהמספר שלילי. רק כפל או חילוק במספר שלילי.

עיגול ריק או מלא

> או <: העיגול ריק. המספר עצמו לא פתרון.

≥ או ≤: העיגול מלא. המספר עצמו כן פתרון.

למה הסימן מתהפך? 2 < 3, נכון? כופלים את שני הצדדים ב-−1 ומקבלים −2 ו-−3. אבל −2 גדול מ-−3. אז עכשיו צריך −2 > −3. הסימן התהפך.

7

שאלות שכולם שואלים

למה הופכים את הסימן כשכופלים במספר שלילי?

כי מספר שלילי הופך את הסדר על ציר המספרים. 2 < 3, אבל אחרי כפל ב-−1 מקבלים −2 ו-−3, ו-−2 > −3. אותו דבר קורה בחילוק במספר שלילי. נסו במעבדה למעלה ושימו a שלילי.

איך מסמנים פתרון של אי-שוויון על ציר המספרים?

שמים עיגול על המספר ומציירים קרן: ימינה לגדול מ, שמאלה לקטן מ. העיגול ריק ב-> או <, ומלא ב-≥ או ≤, כי אז גם המספר עצמו פתרון. החליפו סימן במעבדה ותראו את הציר משתנה.

מה ההבדל בין משוואה לאי-שוויון?

למשוואה כמו 2x = 6 יש פתרון אחד, x = 3. לאי-שוויון כמו 2x > 6 יש אינסוף פתרונות: כל מספר גדול מ-3. פותרים כמעט אותו דבר, רק שבכפל או חילוק במספר שלילי הסימן מתהפך. תרגלו למטה.
