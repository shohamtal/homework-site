משוואות ממעלה ראשונה משוואה היא מאזניים

במשוואה יש מספר שמתחבא, ואנחנו קוראים לו x. משוואה היא כמו מאזניים מאוזנים: מה שעושים לצד אחד, עושים גם לצד השני. ככה x נשאר לבד ומגלים מה הוא. במעבדה מזיזים מחוונים ורואים מה קורה, ובתרגול מקבלים רמזים במקום תשובות.

1

הרעיון

מה זו משוואה?

שני צדדים ובאמצע סימן שווה: 3x + 7 = 22.

x הוא הנעלם, המספר שאנחנו מחפשים.

לפתור משוואה זה למצוא איזה מספר שמים במקום x כדי ששני הצדדים יהיו שווים.

הכלל של המאזניים

אפשר להוסיף, לחסר, לכפול או לחלק, בתנאי שעושים את אותו דבר בשני הצדדים.

ככה המאזניים נשארים מאוזנים, והמשוואה נשארת נכונה.

המטרה: להשאיר את x לבד בצד אחד.

הסדר הקבוע

1. אם יש x בשני הצדדים, אוספים את כולם לצד אחד.

2. מעבירים את המספרים לצד השני.

3. מחלקים במספר שליד x.

4. בודקים: מציבים את התשובה במשוואה.

2

מעבדה: מאזנים את המאזניים

בנו משוואה ax + b = c, ואז נחשו מה x בעזרת המחוון האחרון. כשהמאזניים מאוזנים, מצאתם את הפתרון.

נסו את אלה:

3

שלוש מלכודות

העברה בלי להחליף סימן

x + 5 = 12. כדי להיפטר מה-5, מחסרים 5 משני הצדדים: x = 7.

מי שכותב x = 17 העביר את ה-5 בלי להחליף לו סימן.

שכחו לחלק

4x = 20 זה עוד לא הסוף. 4x פירושו 4 פעמים x.

מחלקים את שני הצדדים ב-4: x = 5.

עשו פעולה רק בצד אחד

2x + 6 = 10. מחלקים ב-2? צריך לחלק את הכול: x + 3 = 5.

לא רק את 2x, וגם לא רק את צד שמאל.

הרגל טוב: בסוף תמיד בודקים. מציבים את התשובה במקום x ומחשבים כל צד לבד. אם יצא אותו מספר בשני הצדדים, התשובה נכונה.

6

שאלות שכולם שואלים

איך פותרים משוואה ממעלה ראשונה?

משאירים את x לבד בצד אחד. קודם מעבירים את המספרים לצד השני, אחר כך מחלקים במספר שליד x. למשל 3x + 7 = 22: מחסרים 7 ומקבלים 3x = 15, ואז מחלקים ב-3 ומקבלים x = 5. נסו במעבדה.

מה עושים כשיש x בשני הצדדים של המשוואה?

מעבירים את כל ה-x לצד אחד ואת כל המספרים לצד השני. ב-5x − 3 = 2x + 9 מחסרים 2x משני הצדדים ומקבלים 3x − 3 = 9. משם ממשיכים כרגיל. ראו בדוגמה ב.

איך בודקים שהפתרון של המשוואה נכון?

מציבים את המספר שמצאתם במקום x ומחשבים כל צד לבד. אם בשני הצדדים יוצא אותו מספר, הפתרון נכון. אם לא, יש טעות באחד הצעדים, וכדאי לעבור עליהם שוב. תרגלו למטה.
