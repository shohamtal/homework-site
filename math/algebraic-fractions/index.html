שברים אלגבריים: צמצום, כפל וחיבור מפרקים, ואז מצמצמים

שבר אלגברי הוא שבר שיש בו x במונה או במכנה. עובדים איתו כמו עם שבר רגיל, עם שני כללים חשובים: אסור לחלק באפס, ומצמצמים רק כפל. במעבדה מזיזים מחוונים ורואים מה קורה, ובתרגול מקבלים רמזים במקום תשובות.

הרעיון

תחום הגדרה

5x − 2

אסור לחלק באפס. המכנה יוצא 0 כש-x = 2, אז כותבים: תחום ההגדרה הוא x ≠ 2.

מוצאים אותו תמיד לפני שמצמצמים.

צמצום: מפרקים קודם

כמו ש-69 = 2 · 33 · 3 = 23, גם כאן מפרקים לגורמים ומצמצמים גורם שמופיע למעלה ולמטה:

x² − 9x − 3 = (x + 3)(x − 3)x − 3 = x + 3

הפירוק הוא פירוק לגורמים או פירוק טרינום.

כפל וחיבור

כפל: מונה כפול מונה, מכנה כפול מכנה, ואז מצמצמים.

חיבור: צריך מכנה משותף, בדיוק כמו 12 + 13 = 3 + 26.

2x + 3x = 5x: כשהמכנה זהה, מחברים רק את המונים.

הכלל של הצמצום: מצמצמים רק גורמים, דברים שמוכפלים בכל המונה ובכל המכנה. איבר שמחובר אי אפשר למחוק. ב-x + 66 אסור למחוק את ה-6, כי הוא מחובר ל-x, לא מוכפל בו.
2

מעבדה: השבר והחור בגרף

השבר (x + a)(x + b)x + a מצטמצם ל-x + b. אבל הוא לא בדיוק אותו דבר: בנקודה אחת השבר לא מוגדר, ובגרף יש שם חור.

שלוש מלכודות

מוחקים איבר מחובר

x² + 4x + 2: אי אפשר "למחוק" ולקבל x + 2.

בדקו עם x = 1: השבר הוא 53, ו-1 + 2 = 3. לא שווה. x² + 4 לא מתפרק, אז השבר כבר מצומצם.

שוכחים את תחום ההגדרה

אחרי הצמצום x² − 9x − 3 = x + 3, ה-x − 3 נעלם מהמכנה.

אבל עדיין x ≠ 3! תחום ההגדרה נקבע מהשבר המקורי.

סוגריים הפוכים

2 − xx − 2 נראה כמו 1, אבל הוא −1.

כי 2 − x = −(x − 2). מוציאים מינוס, ורק אז מצמצמים.

שאלות שכולם שואלים

איך מצמצמים שבר אלגברי?

מפרקים לגורמים את המונה ואת המכנה, למשל בהוצאת גורם משותף, בהפרש ריבועים או בפירוק טרינום. אחר כך מוחקים גורם שמופיע גם למעלה וגם למטה. למשל x² + 5x + 6x + 2 = (x + 2)(x + 3)x + 2 = x + 3. נסו במעבדה.

מה זה תחום הגדרה של שבר אלגברי?

אלה כל המספרים שמותר להציב ב-x. אסור שהמכנה יהיה 0, אז מוציאים מהתחום כל x שמאפס אותו. ב-1x(x + 4) התחום הוא x ≠ 0 וגם x ≠ −4. מוצאים את התחום לפני הצמצום.

איך מחברים שברים אלגבריים עם מכנים שונים?

מוצאים מכנה משותף, בדרך כלל המכפלה של המכנים, ומרחיבים כל שבר אליו. למשל 2x + 3x + 1 = 2(x + 1) + 3xx(x + 1) = 5x + 2x(x + 1). ראו את הדוגמה הפתורה.
