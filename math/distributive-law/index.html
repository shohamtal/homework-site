חוק הפילוג: פתיחת סוגריים כל אחד בסוגריים מקבל את הכפל

מה עושים עם 3(x + 4)? המספר שבחוץ כופל את כל מה שבפנים: 3x + 12. זה חוק הפילוג. במעבדה מזיזים מחוונים ורואים מה קורה, ובתרגול מקבלים רמזים במקום תשובות.

1

הרעיון

הכלל

a(b + c) = ab + ac

המספר שמחוץ לסוגריים נכנס ומכפיל כל איבר בפנים. כל אחד, לא רק את הראשון.

רואים את זה במלבן

מלבן בגובה 3 וברוחב x + 4. השטח שלו: 3(x + 4).

חותכים אותו לשני חלקים: 3 · x ועוד 3 · 4. ביחד 3x + 12. אותו מלבן, אותו שטח.

גם עם מינוס

2(x − 5) = 2x − 10.

−2(x − 5) = −2x + 10, כי מינוס כפול מינוס זה פלוס.

אחרי פתיחת הסוגריים בדרך כלל מכנסים איברים דומים, כדי שהביטוי יהיה קצר.
2

מעבדה: מלבן השטח

בנו ביטוי בצורה a(px + q). המלבן מראה את שני החלקים. חלק עם קו אדום מקווקו הוא שלילי.

3

שלוש מלכודות

כפלו רק את הראשון

3(x + 4) זה לא 3x + 4.

גם ה-4 מקבל את הכפל: 3x + 12. במלבן רואים: לחלק של ה-4 יש גובה 3, בדיוק כמו לחלק של ה-x.

מינוס כפול מינוס

−4(x − 2): −4 · x = −4x ו-−4 · (−2) = +8.

התשובה: −4x + 8, ולא −4x − 8.

מינוס לבד לפני הסוגריים

−(x + 3) זה −1 · (x + 3).

כל סימן בפנים מתהפך: −x − 3.

תמיד אפשר לבדוק: הציבו מספר, למשל x = 2, לפני הפתיחה ואחריה. אם יוצא אותו דבר, פתחתם נכון.

7

שאלות שכולם שואלים

מה זה חוק הפילוג?

חוק הפילוג אומר שכשכופלים מספר בסכום, אפשר לכפול אותו בכל אחד מהמחוברים ולחבר: a(b + c) = ab + ac. למשל 5(x + 2) = 5x + 10. ראו את זה במלבן במעבדה.

איך פותחים סוגריים כשיש מינוס לפניהם?

המינוס נכנס יחד עם המספר ומכפיל כל איבר בפנים, ולכן כל סימן בסוגריים מתהפך. −3(x − 4) = −3x + 12, ו-−(x + 7) = −x − 7. תרגלו למטה.

איך משתמשים בחוק הפילוג בחשבון בעל פה?

מפרקים מספר קשה למספר עגול ועוד משהו קטן. 7 · 102 = 7(100 + 2) = 700 + 14 = 714. וגם 6 · 98 = 6(100 − 2) = 600 − 12 = 588. נסו את האתגר.
