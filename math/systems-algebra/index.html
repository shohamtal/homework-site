מערכת משוואות: שיטת ההצבה וההשוואה

בגרף לא תמיד רואים את נקודת המפגש בדיוק. בחשבון כן. יש שתי דרכים: שיטת ההצבה ושיטת השוואת המקדמים. בשתיהן הופכים שתי משוואות עם x ו-y למשוואה אחת עם x בלבד. במעבדה מזיזים מחוונים ורואים מה קורה, ובתרגול מקבלים רמזים במקום תשובות.

1

שתי השיטות

המטרה בשתי השיטות זהה: להיפטר מאחד הנעלמים, לפתור משוואה רגילה, ואז למצוא גם את השני.

שיטת ההצבה

מתאימה כשאחת המשוואות כבר אומרת כמה זה y.

y = 2x − 1   ו-   x + y = 5

שמים את 2x − 1 במקום y: x + 2x − 1 = 5

ולכן 3x = 6, כלומר x = 2. ואז y = 2 · 2 − 1 = 3.

שיטת השוואת המקדמים

מתאימה כשלנעלם אחד יש אותו מספר לפניו בשתי המשוואות (או מספרים הפוכים).

x + y = 7   ו-   x − y = 1

מחברים את המשוואות, וה-y נעלם: 2x = 8, כלומר x = 4.

מציבים: 4 + y = 7, ולכן y = 3.

התשובה של מערכת היא זוג מספרים: x וגם y. מצאתם רק את x? עוד לא סיימתם.
2

מעבדה: שיטת ההצבה בשידור חי

המערכת: y = mx + b ו-ax + y = c. הזיזו את המחוונים ותראו את כל שלבי ההצבה. בגרף רואים את שני הקווים ואת הפתרון.

3

שלוש מלכודות

סוגריים בהצבה

כשמציבים ביטוי במקום y, שמים אותו בסוגריים. במיוחד אם יש מספר לפני ה-y.

3x + 2y = 12 עם y = x + 1 נהיה 3x + 2(x + 1) = 12.

פותחים: 2(x + 1) = 2x + 2. לא 2x + 1!

חיסור של משוואה שלמה

כשמחסירים משוואות, מחסירים כל איבר, גם את המספר בצד ימין.

(2x + y) − (x + y) = 9 − 5, ולכן x = 4.

זהירות במינוסים: 3 − (−2) = 5.

בסוף, תמיד בודקים. מציבים את x ואת y שמצאתם בשתי המשוואות המקוריות. אם אחת לא יוצאת נכונה, יש טעות בדרך.

דוגמה פתורה, צעד אחרי צעד

5

תרגול: פתרו את המערכת

בחרו שיטה, פתרו במחברת וכתבו את x ואת y. התשובות הן מספרים שלמים.

6

שאלות שכולם שואלים

מתי עדיף שיטת ההצבה ומתי שיטת ההשוואה?

אם באחת המשוואות y (או x) כבר לבד, הצבה הכי קלה. אם לאחד הנעלמים יש אותו מקדם בשתי המשוואות, או מקדמים הפוכים, השוואת מקדמים מהירה יותר. תרגלו את שתיהן למטה.

איך בודקים שהפתרון נכון?

מציבים את x ואת y בשתי המשוואות המקוריות. אם שתיהן יוצאות נכונות, הפתרון נכון. התרגול למטה בודק בדיוק את זה.

מה קורה כשהמשתנה נעלם באמצע הפתרון?

אם נעלמו גם x וגם y ויצא משהו שתמיד נכון, כמו 0 = 0, יש אינסוף פתרונות. אם יצא משהו שאף פעם לא נכון, כמו 0 = 2, אין פתרון בכלל. נסו במעבדה למעלה עם הכפתורים "אין פתרון" ו"אינסוף פתרונות".
