Third Conditional באנגלית If we had known, we would have come

משפט תנאי על העבר, על משהו שלא קרה: If we had heard the alarm, we would have caught the bus. לא שמענו, ולא הספקנו. בחלק של if שמים had וצורה שלישית, ובתוצאה would have וצורה שלישית. כאן מחזירים את היום אחורה, משווים לשני סוגי התנאי הקודמים, ושומעים כל משפט.

הרעיוןמעבדהמלכודותדוגמהתרגולשאלות
1

הרעיון

משהו כבר קרה, או לא קרה, ואי אפשר לשנות אותו. בכל זאת מדמיינים: מה היה קורה אילו? התנאי הוא had וצורה שלישית. התוצאה היא would have וצורה שלישית. לחצו על כרטיס ושמעו.

הנוסחה: If + had + V3, would have + V3. את הצורה השלישית (V3) מכירים מ-Present Perfect: go, went, gone. כמו בעברית: "אילו ידענו, היינו באים".

שלושה סוגי תנאי

סוגמתיהמבנהדוגמה
Firstיכול באמת לקרותIf + present, will + verbIf it rains, we will stay home.
Secondדמיון על עכשיו או על העתידIf + past, would + verbIf it rained, we would stay home.
Thirdעבר שלא קרה, ואי אפשר לשנותIf + had + V3, would have + V3If it had rained, we would have stayed home.
2

מעבדה: מחזירים את היום אחורה

מה היה קורה אילו…?

היום הלך לא טוב. בחרו מה הייתם משנים. רק התוצאות שמתאימות יידלקו. בחרו תוצאה, ומירי תקרא את המשפט. הכפתור "הופכים את הסדר" שם את התוצאה בהתחלה, ואז אין פסיק.

 
כל המשפטים, בשני הסדרים
  • ⏰ If we had heard the alarm, we would have caught the bus. אילו שמענו את השעון המעורר, היינו מספיקים לאוטובוס.
    הסדר ההפוך: We would have caught the bus if we had heard the alarm.
  • ⏰ If we had heard the alarm, we would not have been late. אילו שמענו את השעון המעורר, לא היינו מאחרים.
    הסדר ההפוך: We would not have been late if we had heard the alarm.
  • ☔ If we had taken umbrellas, we would have stayed dry. אילו לקחנו מטריות, היינו נשארים יבשים.
    הסדר ההפוך: We would have stayed dry if we had taken umbrellas.
  • ☔ If we had taken umbrellas, we could have walked home. אילו לקחנו מטריות, היינו יכולים ללכת הביתה ברגל.
    הסדר ההפוך: We could have walked home if we had taken umbrellas.
  • 📚 If they had studied, they would have passed the test. אילו הם היו לומדים, הם היו עוברים את המבחן.
    הסדר ההפוך: They would have passed the test if they had studied.
  • 📚 If they had studied, they might have finished first. אילו הם היו לומדים, אולי הם היו מסיימים ראשונים.
    הסדר ההפוך: They might have finished first if they had studied.
  • 🗺️ If you had checked the map, you would have found the park. אילו בדקתם את המפה, הייתם מוצאים את הפארק.
    הסדר ההפוך: You would have found the park if you had checked the map.
  • 🗺️ If you had checked the map, you could have arrived on time. אילו בדקתם את המפה, הייתם יכולים להגיע בזמן.
    הסדר ההפוך: You could have arrived on time if you had checked the map.
  • ⚽ If he had passed the ball, his team would have won. אילו הוא היה מוסר את הכדור, הקבוצה שלו הייתה מנצחת.
    הסדר ההפוך: His team would have won if he had passed the ball.
  • ⚽ If he had passed the ball, they might have scored a goal. אילו הוא היה מוסר את הכדור, אולי הם היו מבקיעים גול.
    הסדר ההפוך: They might have scored a goal if he had passed the ball.
  • 🔋 If we had charged the phone, we could have called you. אילו טעננו את הטלפון, היינו יכולים להתקשר אליכם.
    הסדר ההפוך: We could have called you if we had charged the phone.
  • 🔋 If we had charged the phone, we would have taken photos. אילו טעננו את הטלפון, היינו מצלמים תמונות.
    הסדר ההפוך: We would have taken photos if we had charged the phone.

ראשון, שני או שלישי?

בחרו רעיון, ואז הזיזו את המתג בין שלושת הסוגים. שימו לב מה קורה לפועל בכל חלק.

 
כל השלישיות
  • 🌧️ קורה באמת: If it rains, we will stay home. אם ירד גשם, נישאר בבית.
    דמיון עכשיו: If it rained, we would stay home. אילו ירד גשם, היינו נשארים בבית.
    עבר שלא קרה: If it had rained, we would have stayed home. אילו ירד גשם אתמול, היינו נשארים בבית.
  • ⏳ קורה באמת: If we have time, we will visit you. אם יהיה לנו זמן, נבקר אתכם.
    דמיון עכשיו: If we had time, we would visit you. אילו היה לנו זמן, היינו מבקרים אתכם.
    עבר שלא קרה: If we had had time, we would have visited you. אילו היה לנו זמן אז, היינו מבקרים אתכם.
  • 🏆 קורה באמת: If we win, we will celebrate. אם ננצח, נחגוג.
    דמיון עכשיו: If we won, we would celebrate. אילו ניצחנו, היינו חוגגים.
    עבר שלא קרה: If we had won, we would have celebrated. אילו ניצחנו במשחק של אתמול, היינו חוגגים.
  • 🚌 קורה באמת: If she misses the bus, she will walk. אם היא תפספס את האוטובוס, היא תלך ברגל.
    דמיון עכשיו: If she missed the bus, she would walk. אילו היא פספסה את האוטובוס, היא הייתה הולכת ברגל.
    עבר שלא קרה: If she had missed the bus, she would have walked. אילו היא הייתה מפספסת את האוטובוס אתמול, היא הייתה הולכת ברגל.
3

מלכודות

אין would אחרי if

לא נכון: If we would have known. נכון: If we had known, we would have come. את would have שמים רק בתוצאה.

would have ולא would of

בדיבור אומרים would've, וזה נשמע כמו would of. אבל כותבים would have או would've. ככה גם could have ו-might have.

לא מערבבים עם ה-Second

אם המבחן היה אתמול, לא אומרים If they studied, they would pass the test. זה דמיון על עכשיו. על אתמול אומרים If they had studied, they would have passed the test.

צורה שלישית, לא עבר

לא נכון: we would have went. נכון: we would have gone. אחרי have ואחרי had באה הצורה השלישית.

שאלות שהורים שואלים

מה זה Third Conditional באנגלית?

משפט תנאי על העבר, על משהו שלא קרה. בחלק של if שמים had וצורה שלישית, ובתוצאה would have וצורה שלישית: If we had known, we would have come. "אילו ידענו, היינו באים". משתמשים בו לחרטה, להסבר ולדמיון על מה שהיה יכול להיות.

מה ההבדל בין Second Conditional ל-Third Conditional?

Second מדבר על דמיון עכשיו: If it rained, we would stay home. Third מדבר על עבר שכבר נגמר: If it had rained, we would have stayed home. אפשר לשאול את הילדים: "זה כבר קרה?" אם כן, צריך Third.

איך עוזרים לזכור את הצורה השלישית של הפועל?

מתרגלים את שלוש הצורות ביחד, בקול: go, went, gone, see, saw, seen, take, took, taken. במבנה הזה רק הצורה השלישית מופיעה, גם אחרי had וגם אחרי would have. כדאי לחזור קודם על Present Perfect, שם פוגשים אותה לראשונה.
