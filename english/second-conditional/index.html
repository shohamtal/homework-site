Second Conditional באנגלית If I had wings, I would fly

משפט תנאי על דברים דמיוניים, או על דברים שכנראה לא יקרו: If I had wings, I would fly. בחלק של if שמים עבר, ובחלק של התוצאה would. כאן בונים משפטי חלומות, הופכים תנאי אמיתי לתנאי דמיוני, ושומעים כל משפט.

הרעיוןמעבדהמלכודותדוגמהתרגולשאלות
1

הרעיון

גם כאן יש שני חלקים. התנאי מתחיל ב-if והוא בעבר, אבל זה לא באמת עבר: העבר אומר "זה דמיון". התוצאה משתמשת ב-would ופועל. לחצו על כרטיס ושמעו.

הנוסחה: If + Past Simple, would + verb. כמו בעברית: "אילו הייתי ציפור, הייתי עפה".

2

מעבדה: מכונת החלומות

מה היה קורה אילו…?

בחרו חלום. רק התוצאות שמתאימות לו יידלקו. בחרו תוצאה, ומירי תקרא את המשפט. הכפתור "הופכים את הסדר" שם את התוצאה בהתחלה, ואז אין פסיק.

 
כל המשפטים, בשני הסדרים
  • 🪽 If we had wings, we would fly to school. אילו היו לנו כנפיים, היינו עפים לבית הספר.
    הסדר ההפוך: We would fly to school if we had wings.
  • 🪽 If we had wings, we would touch the clouds. אילו היו לנו כנפיים, היינו נוגעים בעננים.
    הסדר ההפוך: We would touch the clouds if we had wings.
  • 🧑‍🏫 If I were the teacher, there would be no homework. אילו הייתי המורה, לא היו שיעורי בית.
    הסדר ההפוך: There would be no homework if I were the teacher.
  • 🧑‍🏫 If I were the teacher, every lesson would be a game. אילו הייתי המורה, כל שיעור היה משחק.
    הסדר ההפוך: Every lesson would be a game if I were the teacher.
  • 💰 If we had a million shekels, we would buy a big house. אילו היו לנו מיליון שקלים, היינו קונים בית גדול.
    הסדר ההפוך: We would buy a big house if we had a million shekels.
  • 💰 If we had a million shekels, we would travel around the world. אילו היו לנו מיליון שקלים, היינו נוסעים מסביב לעולם.
    הסדר ההפוך: We would travel around the world if we had a million shekels.
  • 🐶 If my dog could talk, it would tell me jokes. אילו הכלב שלי היה יכול לדבר, הוא היה מספר לי בדיחות.
    הסדר ההפוך: It would tell me jokes if my dog could talk.
  • 🐶 If my dog could talk, it would ask for more food. אילו הכלב שלי היה יכול לדבר, הוא היה מבקש עוד אוכל.
    הסדר ההפוך: It would ask for more food if my dog could talk.
  • 👻 If you were invisible, nobody would see you. אילו הייתם בלתי נראים, אף אחד לא היה רואה אתכם.
    הסדר ההפוך: Nobody would see you if you were invisible.
  • 👻 If you were invisible, you would play tricks on your friends. אילו הייתם בלתי נראים, הייתם עושים תעלולים לחברים.
    הסדר ההפוך: You would play tricks on your friends if you were invisible.
  • 🌙 If we lived on the moon, we would jump very high. אילו גרנו על הירח, היינו קופצים גבוה מאוד.
    הסדר ההפוך: We would jump very high if we lived on the moon.
  • 🌙 If we lived on the moon, we would see the Earth every night. אילו גרנו על הירח, היינו רואים את כדור הארץ כל לילה.
    הסדר ההפוך: We would see the Earth every night if we lived on the moon.

אמיתי או דמיון?

בחרו רעיון, ואז הזיזו את המתג. "קורה באמת" נותן First Conditional עם הווה ו-will. "דמיון" נותן Second Conditional עם עבר ו-would. שימו לב מה משתנה.

 
כל הזוגות
  • ⏳ קורה באמת: If we have time, we will visit you. אם יהיה לנו זמן, נבקר אתכם.
    דמיון: If we had time, we would visit you. אילו היה לנו זמן, היינו מבקרים אתכם.
  • ⛄ קורה באמת: If it snows, we will build a snowman. אם ירד שלג, נבנה איש שלג.
    דמיון: If it snowed, we would build a snowman. אילו ירד שלג, היינו בונים איש שלג.
  • 🏆 קורה באמת: If we win, we will celebrate. אם ננצח, נחגוג.
    דמיון: If we won, we would celebrate. אילו ניצחנו, היינו חוגגים.
  • 📚 קורה באמת: If she studies, she will pass the test. אם היא תלמד, היא תעבור את המבחן.
    דמיון: If she studied, she would pass the test. אילו היא למדה, היא הייתה עוברת את המבחן.

השיר

מירי שרה שורה, ואז תורכם. המילה שצריך להגיד עכשיו צבועה בצהוב. הזיזו את המחוון כדי לשיר לאט או מהר.

If I had wings, I would fly,
high above the big blue sky.
If I were a fish, I would swim
under the sea all day long!

המנגינה: Twinkle, Twinkle, Little Star, שיר עם עממי. המילים שלנו.

3

מלכודות

אין would אחרי if

את would שמים רק בתוצאה. לא נכון: If I would have wings. נכון: If I had wings, I would fly.

If I were ולא If I was

בתנאי דמיוני אומרים were לכל הגופים: If I were you, I would rest. בדיבור שומעים גם was, אבל במבחן כותבים were.

עבר שהוא לא עבר

If I had a dog לא מדבר על אתמול. הוא אומר "אין לי כלב, אבל אילו היה". העבר כאן הוא סימן לדמיון.

אחרי would בא פועל בסיסי

לא נכון: I would flew. נכון: I would fly. בקיצור אפשר לומר I'd fly.

6

שאלות שכולם שואלים

מה זה Second Conditional באנגלית?

משפט תנאי על משהו דמיוני, או על משהו שכנראה לא יקרה. בחלק של if שמים עבר, ובחלק של התוצאה would ופועל: If I had wings, I would fly. "אילו היו לי כנפיים, הייתי עפה".

מה ההבדל בין First Conditional ל-Second Conditional?

ב-First Conditional מדברים על משהו שיכול באמת לקרות: If it snows, we will build a snowman. ב-Second Conditional זה דמיון או משהו לא סביר: If it snowed, we would build a snowman. בראשון יש הווה ו-will, בשני עבר ו-would.

למה אומרים If I were ולא If I was?

במשפט תנאי דמיוני משתמשים ב-were לכל הגופים: If I were you, I would rest. בדיבור יומיומי שומעים גם If I was, אבל בבית הספר ובמבחנים כותבים were.
