Mixed Conditionals באנגלית If we had slept, we would feel fresh now

לפעמים התנאי והתוצאה לא באותו זמן. משהו קרה בעבר, והתוצאה מורגשת עכשיו: If we had slept well, we would feel fresh now. או מצב של עכשיו, ותוצאה בעבר: If we were braver, we would have spoken at the meeting. כאן מזיזים את מכונת הזמן, בונים את המשפט ושומעים אותו. רוצים לחזור קודם? בThird Conditional שני החלקים בעבר.

1

הרעיון

ב-Mixed Conditional שואלים שתי שאלות: מתי התנאי? ומתי התוצאה? כל חלק מקבל את הזמן שלו. לחצו על כרטיס ושמעו.

עבר ← עכשיו

If + had + V3, would + V1
משהו שלא קרה בעבר משנה את ההווה: If he had trained harder last year, he would play for the team now.

עכשיו ← עבר

If + past simple, would have + V3
מצב שנכון תמיד, גם עכשיו, הסביר משהו בעבר: If he were taller, he would have joined the team last September.

מעבדה: מכונת הזמן

בחרו סיפור. אחר כך הזיזו את שני המחוונים: מתי התנאי, ומתי התוצאה. המשפט נבנה מחדש, ומירי קוראת אותו.

כל המשפטים של מכונת הזמן
  • 🎵 Third Conditional: If we had learned Spanish as kids, we would have understood the guide in Madrid last summer. אילו למדנו ספרדית בילדות, היינו מבינים את המדריך במדריד בקיץ שעבר.
    Mixed: עבר ← עכשיו: If we had learned Spanish as kids, we would understand this song now. אילו למדנו ספרדית בילדות, היינו מבינים את השיר הזה עכשיו.
    Mixed: עכשיו ← עבר: If we spoke Spanish, we would have understood the guide in Madrid last summer. אילו דיברנו ספרדית, היינו מבינים את המדריך במדריד בקיץ שעבר.
    Second Conditional: If we spoke Spanish, we would understand this song now. אילו דיברנו ספרדית, היינו מבינים את השיר הזה עכשיו.
  • 🏀 Third Conditional: If he had trained harder last year, he would have joined the team last September. אילו הוא היה מתאמן יותר בשנה שעברה, הוא היה מצטרף לקבוצה בספטמבר שעבר.
    Mixed: עבר ← עכשיו: If he had trained harder last year, he would play for the team now. אילו הוא היה מתאמן יותר בשנה שעברה, הוא היה משחק בקבוצה עכשיו.
    Mixed: עכשיו ← עבר: If he were taller, he would have joined the team last September. אילו הוא היה גבוה יותר, הוא היה מצטרף לקבוצה בספטמבר שעבר.
    Second Conditional: If he were taller, he would play for the team now. אילו הוא היה גבוה יותר, הוא היה משחק בקבוצה עכשיו.
  • 🚲 Third Conditional: If she had saved her pocket money, she would have bought the bike last month. אילו היא הייתה חוסכת את דמי הכיס שלה, היא הייתה קונה את האופניים בחודש שעבר.
    Mixed: עבר ← עכשיו: If she had saved her pocket money, she would be able to pay for the trip now. אילו היא הייתה חוסכת את דמי הכיס שלה, היא הייתה יכולה לשלם על הטיול עכשיו.
    Mixed: עכשיו ← עבר: If she were more careful with money, she would have bought the bike last month. אילו היא הייתה זהירה יותר עם כסף, היא הייתה קונה את האופניים בחודש שעבר.
    Second Conditional: If she were more careful with money, she would be able to pay for the trip now. אילו היא הייתה זהירה יותר עם כסף, היא הייתה יכולה לשלם על הטיול עכשיו.
  • 🌊 Third Conditional: If they had moved to the coast, they would have learned to surf as children. אילו הם היו עוברים לגור ליד החוף, הם היו לומדים לגלוש בילדות.
    Mixed: עבר ← עכשיו: If they had moved to the coast, they would swim every morning now. אילו הם היו עוברים לגור ליד החוף, הם היו שוחים כל בוקר עכשיו.
    Mixed: עכשיו ← עבר: If they lived near the sea, they would have learned to surf as children. אילו הם היו גרים ליד הים, הם היו לומדים לגלוש בילדות.
    Second Conditional: If they lived near the sea, they would swim every morning now. אילו הם היו גרים ליד הים, הם היו שוחים כל בוקר עכשיו.
  • 🔋 Third Conditional: If we had charged the phone last night, we would have called you an hour ago. אילו טענו את הטלפון אתמול בלילה, היינו מתקשרים אליכם לפני שעה.
    Mixed: עבר ← עכשיו: If we had charged the phone last night, the phone would be working now. אילו טענו את הטלפון אתמול בלילה, הטלפון היה עובד עכשיו.
    Mixed: עכשיו ← עבר: If we were not so forgetful, we would have called you an hour ago. אילו לא היינו כל כך שכחנים, היינו מתקשרים אליכם לפני שעה.
    Second Conditional: If we were not so forgetful, the phone would be working now. אילו לא היינו כל כך שכחנים, הטלפון היה עובד עכשיו.
3

מלכודות

אין would אחרי if

לא נכון: If he would have trained harder last year… נכון: If he had trained harder last year, he would play for the team now. את would שמים רק בתוצאה.

לא מערבבים בלי סיבה

לא נכון: If we had learned Spanish as kids, we would have understood this song now. המילה now אומרת שהתוצאה עכשיו, לכן: If we had learned Spanish as kids, we would understand this song now.

מילים שמסמנות זמן

עכשיו: now, today, still, these days ← would + V1.
עבר: yesterday, last year, ago, as children ← would have + V3.
מצב קבוע כמו taller, braver, lived near the sea ← past simple בתנאי.

were לכולם

בתנאי דמיוני כותבים If he were taller ו-If I were braver. בדיבור שומעים גם was, אבל בבחינה כדאי לכתוב were.

4

דוגמה: בונים משפט מעורב

כל המשפטים של הדוגמה
  • If we had slept well, we would feel fresh now.
  • If we had slept well, we would have done better on the test yesterday.
  • If we were braver, we would have spoken at the meeting.
5

תרגול

רוצים לחזור על עבר שלא קרה? חוזרים לThird Conditional. לפני הבגרות כדאי לעבור על החזרה על הדקדוק לבגרות, עם כל הזמנים והתנאים במקום אחד.

6

שאלות שהורים שואלים

מה זה Mixed Conditional באנגלית?

משפט תנאי שבו התנאי והתוצאה בזמנים שונים. הנפוץ ביותר: תנאי בעבר ותוצאה עכשיו, If we had slept well, we would feel fresh now. "אילו ישנו טוב, היינו מרגישים רעננים עכשיו". יש גם הפוך: מצב של עכשיו ותוצאה בעבר, If we were braver, we would have spoken at the meeting.

איך יודעים מתי לערבב?

שואלים שתי שאלות: מתי התנאי? מתי התוצאה? אם שניהם בעבר, זה Third. אם שניהם עכשיו, זה Second. אם הם שונים, מערבבים. מילים כמו now, yesterday ו-last year עוזרות לזהות.

זה באמת מופיע בבגרות?

כן, בעיקר בקטעי unseen ובחיבורים ברמה של 5 יחידות. הילדים צריכים לזהות את המבנה ולהבין את המשמעות, ולא רק לשנן נוסחה. כדאי לחזור קודם על Second ועל Third, ורק אחר כך לערבב.
