# Homework site — notes for Claude

- Audience: Israeli middle-school kids (started with grade 8 math). Hebrew, RTL, plural address (נסו, בחרו), short simple sentences, no em-dashes, no student names.
- Every topic page follows the same pattern and look: sitebar → header.page → numbered section.card blocks: idea (mini cards) → **slider lab** (the parent's favorite: sliders + live graph + live explanation box + "נסו את אלה" presets) → method / pitfalls callout → worked-example stepper → practice with diagnostic feedback, progressive hints, solution only after 2 wrong tries → topicNav + footer.
- Look: "comic clean" (light only): white dotted background, 2px black outlines with a hard offset shadow (`--hard`), Secular One headings, Rubik body, STIX Two Text for math, pink `--line` accent, yellow `--hl` badges. Thin dividers use `--soft`.
- Reuse `assets/graph.js` (window.G) and `assets/site.css` classes; colors only via tokens.
- Register every new topic in `assets/topics.js`; indexes and prev/next are generated from it. Structure is subject › grade › chapter › topic: `subject.grades` lists the grades (id like `grade-8`), `chapter.grade` is the grade name, `topic.aka` lists the matching names in `curriculum.js`. Topic URLs stay flat (`/math/<slug>/`); grade pages (`/math/grade-8/`) are generated by the build. Breadcrumb: כל המקצועות ‹ מתמטיקה ‹ כיתה ח ‹ chapter ‹ topic.
- Don't copy worksheet content verbatim (worksheets are usually copyrighted, e.g. karnafim.co.il): teach the topic with original examples and exercises.
- Site is public on GitHub Pages (main branch, root).
- Coming-soon subjects: `soon:true` in topics.js (shown as a disabled tile with a בקרוב chip, hidden from the TOC).
- Topic requests: Google Form (personal account shoamtal@gmail.com) + board sheet, no server. Closed topic list per subject+grade in `assets/curriculum.js` (site topics merged in from topics.js and marked "כבר באתר"); "אחר" opens free text that goes to a separate form field and never reaches the public board. Board sheet = QUERY over IMPORTRANGE of the responses sheet, read as gviz CSV. Config `assets/requests-config.js`, logic `assets/requests.js`, page `requests/`.
- Brand: **מירי · המורה שלך להצלחה** (set in `site.config.json` and `SITE.name`). Planned domain `miri-hw.co.il`; don't buy or connect it until the owner says go (`docs/custom-domain.md`).
- **Build:** `node scripts/build.mjs --only <slug>` rebuilds one topic page only. Topics without a page file are skipped everywhere. After editing `assets/topics.js`, `site.config.json` or adding a page, run `node scripts/build.mjs`. It fills the `<!-- build:NAME -->` regions (head/SEO tags + JSON-LD, sitebar, topicnav, toc, subjects, footer) and writes `sitemap.xml` and `llms.txt`. Commit the output; there is no build on deploy. A new page needs the same build markers as the existing ones, and a `title`/`description` entry in `site.config.json` (topic titles default to `<topic> · <chapter> <grade> · מירי`).
- SEO coordination happens with a separate SEO agent through issues in the private repo `shohamtal/miri-hw-seo` (labels `to-dev` / `to-seo` / `needs-owner`).
- Analytics: GoatCounter (no cookies, no Google Analytics). Self-hosted `assets/goatcounter.js` is a copy of `genjutsu-studio/docs/goatcounter.js` (query limited to utm_*/ref); the build adds the tag to every page with endpoint `goatcounter` from `site.config.json` (`miri-hw.goatcounter.com`, separate from Genjutsu's).
